# HomeListingAI deep code audit — October 27, 2026

What this repo does: HomeListingAI builds real-estate listing pages, captures buyer leads, and helps agents and loan officers follow up. It also handles subscriptions, appointments, phone lines, invoices, and automated marketing. Assumed use: a public internet service with multiple unrelated customer accounts and concurrent visitors.

Audited revision: `a1e5a85e0bb201b3cd240be69427ed65bf0862e5` on `main`.

## Verdict

Fix the red findings before treating this revision as ready for wider use. Passing tests do not cover the failures reproduced here. This is a deep code audit, not a claim that every file, screen, or live integration has been tested.

🔴 = security, privacy, billing, or serious data-integrity problem. 🟡 = broken feature, reliability problem, or a dependency/deployment risk needing follow-up.

Evidence labels: **Reproduced** means actual source ran locally with isolated fake dependencies (or a local HTTP server). **Code confirmed** means the failure path is explicit in the source. **Conditional** means the code is unsafe under the stated configuration; the live configuration was not checked.
