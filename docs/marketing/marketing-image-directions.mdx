# Create topic-driven marketing images

Give each post a visual that explains its subject. Keep the dark background and bold headline, then use a different scene and accent palette for each topic.

<Info>
The five owner-approved originals are saved in the private picture library. Matching video campaigns remain drafts. The image prompt rules and Autopilot headline layout use this direction. The component names below assume your documentation site provides Steps, Step, and Info.
</Info>

## How it works

Each image starts with three inputs: the headline, the post's main idea, and a visual metaphor. The headline stays readable while the scene makes the idea concrete.

| Topic | Visual | Accent colors |
| --- | --- | --- |
| Referral network | Houses connected by illuminated cables | Cyan and lime |
| Mortgage strategy | House, chess knight, and changing path | Violet and coral |
| Agent partnerships | Hands building a bridge between homes | Cobalt and pink |
| Open house | Welcoming home and ribbon leading inside | Blue and yellow |
| Business Brain | One brain supporting several listing models | Turquoise and magenta |

Use one main subject. Avoid repeating the same doorway, silhouette, and orange lighting across every post. Color should emphasize the headline and subject without covering the whole image.

## How to use it

<Steps>
  <Step title="Choose the post's main idea">
    Write one sentence describing what the reader should understand. For example: a referral network needs active connections.
  </Step>
  <Step title="Choose a visual">
    Turn that idea into a visible scene, such as houses linked by cables. Use the image directions above as starting points.
  </Step>
  <Step title="Keep the headline clear">
    Use large white type and highlight a key phrase with an accent color. Leave space around every edge.
  </Step>
  <Step title="Review the picture">
    Check the headline spelling, topic match, anatomy, and phone-size readability. Treat the image as an illustration, not a photograph of an actual listing.
  </Step>
  <Step title="Approve before publishing">
    Select a direction before changing the app's image rules. Publishing and production integration are separate work.
  </Step>
</Steps>

## Example brief

This JSON is a creative brief, not an application API request.

```json
{
  "headline": "IS YOUR REFERRAL NETWORK STILL PRODUCING?",
  "idea": "An active referral network connects people and opportunities.",
  "scene": "Miniature houses connected by illuminated cables",
  "background": "deep navy",
  "accents": ["cyan", "lime"],
  "format": "square",
  "avoid": ["repeated doorway silhouette", "fake statistics", "unreadable text"]
}
```

## Example generation prompt

```text
Create one square editorial marketing image for HomeListingAI.
Show detailed miniature houses connected by cyan and lime cables.
Use a deep navy background and a clear central subject.
Place this exact headline in large readable type:
"IS YOUR REFERRAL NETWORK STILL PRODUCING?"
Highlight "REFERRAL NETWORK" with the accent colors.
Keep generous margins and a small HomeListingAI footer.
Do not add performance claims, buttons, or extra copy.
```
